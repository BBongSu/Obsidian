>**참고사항**

- 나이스페이는 문의상담 전화번호가 없음. NICE페이먼츠에 전화해봤더니 1:1 상담채팅 문의로만 가능하다고.. (지인 있으면 직통 추천)

- 테스트 API로 카드결제 외 결제수단(가상계좌,현금영수증 등)을 이용할 경우 제약사항이 존재함. ex) 가상계좌 테스트 API인 경우, return값 중 가상계좌번호 데이터를 제공하지 않음.

- 도메인은 필수 등록. (홈페이지 없는 경우 이용불가) 뒤에 붙는 포트번호는 무관함.

- 카드결제를 사용하지 않아도 카드사 심사는 필수임. ex) 카드사 심사를 완료해야 당사에서 가상계좌에 대한 셋팅이 가능함.

- 홈페이지에 기본적인 가이드는 제공하나 내용이 부족한 경우, 상세한 가이드를 보고 싶은 경우는 GitHub에 마크다운 언어로 업로드 돼있음 (https://github.com/nicepayments/nicepay-manual)
