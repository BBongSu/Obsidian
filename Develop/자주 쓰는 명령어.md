``` bash title="텍스트 수정 정규식"
숫자값인 경우 - [\d]+ 
	ex) data-width="200" => data-width="[\d]+"
	
리터럴 템플릿을 문자열 연결로 바꿀 경우 - \$\{([^}]+)\} => '+ $1 +'
	ex) ${resultData.selfIssue} => '+ resultData.selfIssue +'

MyBatis 변수값 바꿀 경우 - ([a-zA-Z0-9]+) => #{\1\}
	ex) pancCancelledTid => #{pancCancelledTid}

접두사를 제거하고 대문자를 소문자로 바꿀 경우 - 접두사([A-Z]) => \L\1
	ex) pancCancelledTid => cancelledTid
		** 이클립스에선 대문자를 소문자로 바꾸는게 통하지 않음

```
