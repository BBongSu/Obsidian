- 1개월이 지난시점 3번째 블로그 C를 개설
- 스킨 선택, 검색 등록 등 블로그 초기단계 기술적인 설정 완벽세팅

**승인용 글쓰기 노하우
- 공통사항 - 카테고리 2개로 시작 ex) 건강정보, IT기술, 일상 등
- A 블로그 - IT 실무 기술 경험 글 5개 쓰고 8번째 글에서 1주일만에 승인
- B 블로그 - 건강 정보와 유명 놀이공원 갔던 후기 글 총 9개로 5일만에 승인
- C 블로그 - A,B 블로그 개설 후 약 1개월이 지난 시점 비슷한 내용으로 승인
- 승인용 글 컨텐츠는 유니크하거나 다른 사람에게 정보를 전달할 수 있는 가치있는 콘텐츠를 경험이나 후기 형식으로 작성하면 유리

- 일상 카테고리 예 - 어디어디 실내동물원 다녀왔어요!, 아이들과 레고랜드 방문 후기
- 건강 카테고리 예 - 공복에 먹으면 좋은 or 해로운 음식은?, 숙면에 좋은 음식을 소개합니다
- IT 카테고리 예 - 윈도우 or 리눅스 중요 명령어 사용법 사용후기, Linux OS Disk 추가하는 방법

- 구글 서치콘솔 코드 복사 후 head 태그 사이에 추가
- 구글 애널릭틱스 코드 복사 후 head 태그 사이에 추가
- 대출, 보험, 렌탈, 키워드 등 승인 심사 중에 부정적인 영향을 끼칠만한 컨텐츠의 글은 피하자

**기다리기면 하면되나?**

- 많은 글을 써보고 남들은 어떻게 쓰고있는지 분석, 모방
- 어떤 글을 썼을 때 어떤 키워드로 방문자가 얼마나 되는지 통계적 자료를 보고 분석하는 능력을 키워야함

- A 블로그 - daum 검색엔진 최적화에 맞춰 글쓰기
- B 블로그 - 구글을 노린 SEO에 맞게 글쓰기
- C 블로그 - 저품질 상태 기술적인 부분 테스트 및 외부 유입 테스트 (목차, 서식, 스킨변경, 카테고리URL 제거 코드 삽입 등)

- 단기간에 방문자 유입 효과를 확인해보고 싶으면 daum 최적화가 우선
- 중~장기적으로 구글 노출을 노린다면 SEO에 맞는 글쓰기를 꾸준하게 하는게 맞음

- 가장 중요한 포인트는 daum 검색엔진 최적화 시키기와 승인에만 몰두해야함

**에드센스 승인 노하우

- 승인에 유리한 컨텐츠로 글을 쓰자. 유니크한 가치있는 컨텐츠. 경험이나 후기 형식. (돈되는 글은 승인 받은 후 평생 써도 됨)
- 승인 거절이 지속된다면 시간낭비 하지말고 과감하게 블로그 새로 파고 신청.
- 승인 요청 후 할일은 마냥 기다리지말고 다양한 글을 써본다. (남들 포스팅 분석, 모방등)
- 여력이 된다면 승인 받을때 까지 꾸준하게 글을 쓰면 최소한 daum 검색엔진 최적화 확률이 높아짐. 본인 작성 글을 daum 검색 상단 노출을 위해 블로그 최적화 과정. 시간이 안되면 매일 안써도 됨. 1주일에 2~3개도 상관없음. 이 과정에서 글 쓰기는 어차피 광고가 붙지 않은 상태라 큰 정성을 들이지 않아도됨.

 ---

**에드센스로 돈벌기

- 우리의 최종 목표는 어떤 글을(컨텐츠)써서 어떤 방법으로 돈을 벌것이냐

- 저품질 - daum 검색에 내 블로그 글이 노출이 되지 않는 현상. 서서히 단계적으로 진행
	- 초기단계 - 일부 글들이 노출이 되지 않음
	- 저품질 - 전체 글들이 노출이 되지 않음
	- 애매한 저품질 - daum 검색창에 https://xxxx.tistory.com 입력시 사이트탭에 노출안됨

- CPC - 광고 1 클릭당 단가
- CTR - 광고 노출 횟수 대비 광고 클릭 횟수 비율
- RPM - 페이지 노출 수 1000회당 수익 비율

- CPC 단가 높은 컨텐츠만 공략 할것인지?
- CPC 단가는 낮아도 꾸준하게 찾는 안전한 컨텐츠로 갈것인지?
- 이슈성 키워드로 대량 방문자 유입 트래픽으로 단기 수익을 낼것인지?

**애드센스 승인 후 할일

- 컨텐츠 선택은 곧 키워드 선택
- 컨텐츠에 따른 장단점을 이해하고 글을 써야 수익 증진에 도움이 됨
- CPC 단가가 높은 컨텐츠의 글을 쓰는게 좋음
- 만약 SNS 등으로 외부 트래픽 유입에 자신있다면 단기간 수익도 노려볼 수 있음

| 컨텐츠 종류          | 카테고리                 | 예시                                          |
| --------------- | -------------------- | ------------------------------------------- |
| **단가 높은 컨텐츠**   | 보험, 대출, 주식 등         | 상해보험, 생명보험, 담보대출, 신용대출, 반도체 관련주 등           |
| **이슈성 컨텐츠**     | 특정인물이슈, 특별한 날, 특정 사건 | 연예인이슈, 지방선거후보, xx 음주운전, xx결혼 어버이날선물, 가을축제 등 |
| **꾸준하게 찾는 컨텐츠** | 건강, 부동산, 정부지원 정책     | 건강검진, 다이어트, 눈질환, 예금금리, 증명서발급, 환급금조회 등       |

**키워드 선택 및 찾는 방법**

- 잘 선택한 키워드 하나가 벌수 있는 수익은 한계가 없음

1. 일반적인 키워드 선택 방법 ex) 건강보험
	- 검색량 분석 사이트
	- https://blackkiwi.net
	- https://keyzard.org/keyzard

글1) 건강보험 피부양자 자격 조건 알아보자
글2) 건강보험 피부양자 등록방법 알아보자
글3) 건강보험 피부양자 자격조건과 등록방법 알아보자 (자격조건, 등록 두개 키워드 둘다 공략)

2. 광고매칭(수익)을 고려한 키워드 찾는 방법 ex) 건강
	- 구글애드센스 - 광고심사센터 - "건강" 검색 -> 수많은 광고가 많이 나오는데 "관절약" 관련 광고가 유독 많이 보임
	- 관절 건강에 대해 블랙키위나 키자드에서 검색량을 조회

글1) 관절영양제 msm 효능 효과는?
글2) 관절영양제 콘드로이친 가격과 효과는?
글3) 보스웰리아 관절영양제 추천 어떤게 좋을까요?
