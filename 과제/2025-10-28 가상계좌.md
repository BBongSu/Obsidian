## 가상계좌

- 가상계좌를 발급 버튼을 누른다. - 확인
	- 결제금액 = 공급가액 + 부가세 + 봉사료 + 비과세급액 - 확인
- 개인정보를 입력한 후 확인 버튼을 누른다. - 확인
- 테스트 성공했는지 데이터를 확인한다. - 확인
- 화면에서 가상계좌 정보를 불러온다.
	- returnUrl 호출 후 화면에 모달창을 생성해서 가상계좌 정보를 불러온다. - 어려움
	
	- 윈도우 팝업 하나 만들어서 개인정보를 입력한 후 확인 버튼을 누른다.
	- returnUrl 호출 후 윈도우 화면에서 가상계좌 정보를 불러온다.

- 가상계좌에 돈을 입금한다.
	- 7일 이내로 입금을 안하면 가상계좌는 없어지고 처음부터 재개한다.
	- **테스트 입금계좌 - 하나은행 379-910010-05904 (주)헌터코리아엔지니어링**

- 결제확인이 됐으면 결제이력에 추가된다.
- 증빙자료를 열어 영수증을 조회한다.
