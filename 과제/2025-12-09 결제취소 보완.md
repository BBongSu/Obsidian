
1. 세금계산서 / 현금영수증 / 결제취소 진행 후 상세페이지로 출력
	
	방법 1 (추천)
	- 세금계산서 / 현금영수증 등록 시, 입출금관리 데이터에 세금계산서 작성여부 Y / 현금영수증 작성여부 Y 상태 변경 후 Y면 상세, N이면 등록
	
	방법 2
	- 세금계산서 / 현금영수증 등록 시, 입출금관리 데이터를 출력하기 전 데이터 조회. 존재하면 상세 / 존재하지 않으면 등록
	
		설계
		- 세금계산서 / 현금영수증 등록 시, 작성여부 컬럼 2개 추가 및 UPDATE
		- 상태가 Y면 상세페이지로 이동 (rcpTaxDet.jsp / rcpCashDet.jsp)
		- 상세페이지는 p 태그로 출력. 저장 버튼 삭제 및 닫기 버튼 추가
		구현
		- 세금계산서 / 현금영수증 구분하는 데이터 컬럼 존재. 이를 활용
