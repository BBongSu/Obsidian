## Front

- "입금처리" 버튼 클릭 - 완료

- "결제취소 확인" 버튼 클릭 - 완료

- 결제수단별(카드결제/가상계좌/무통장입금/현금) 취소진행 화면 출력

- 취소 가능한 건인지 확인 후
	- 불가능한 경우 - ~사유로 인해 취소가 불가능 및 수동 작업 진행 예/아니오
		- 예인 경우 - 지출결의서 자동 추가 및 출금 처리 수동
		- 아니요인 경우 - 현재 창 닫기
	- 가능한 경우 - 취소 시 유의사항 및 안내글 설명
		- 결제취소인 경우 - 지출결의서 자동 추가 및 출금 처리 수동
		- 닫기인 경우 - 현재 창 닫기

- 취소처리 완료 후 입금관리 상태
	- 카드 - "취소완료"
	- 가상계좌 - "취소대기" - "취소완료"
	- 무통장입금 - "취소대기" - "취소완료"
	- 현금 - "취소대기" - "취소완료"

- "취소대기" 상태인 경우에서 출금처리에서 완료하면 결제이력에 추가
	- 출금 상태는 완료

- 입금관리 상태는 "취소완료" 처리
