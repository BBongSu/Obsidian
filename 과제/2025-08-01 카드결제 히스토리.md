>Trouble Shooting

- API 신청은 헌터코리아 독립형으로 진행한 후 비즈팩 사업자로 요청 예정
- 카드결제 개발연동 방법 2가지

- **APPPOS(앱포스) 연동**
	- 모바일 환경에서 사용 용도
	- 귀사의 앱과 당사 결제 앱인 앱포스가 통신하며, 앱포스가 리더기를 컨트롤하는 방식
	- 블루투스 리더기 사용 필요 (리더기 소개 자료 내 ‘NM-400_BLE’ 참고)

- **NVCAT 연동** **(시리얼)**
	- 안드로이드(모바일 X) 환경에서 사용 용도
	- 귀사의 WEB으로 구동하는 프로그램과 당사의 결제 모듈인 NVCAT이 통신하며, NVCAT 모듈이 리더기를 컨트롤하는 방식
	- 리더기 유선 연결 필수 (리더기 소개 자료 내 ‘NK-2500QN, NR-5700QN, NR-5500QR’ 참고)
	해당 리더기의 기본 동봉 케이블은 Y자 케이블 (POS 본체에 RS232, USB가 둘다 꽂아야 함)이며, 테블릿의 C타입으로 통신 필요시 별도 케이블 구매 필요 (추후 당사 문의 시 상품 안내 가능)


- **APPPOS 연동과 NVCAT 연동이 따로 있다는 말인건가? 난 NVCAT밖에 받은게 없는데**
- **NVCAT 연동은 모바일이 안된다는 말인건가? 그럼 APP 연동은 안된다는 말인건가?**

![[KakaoTalk_20250402_150125088.png]]

- 카드 리더기에서 빨간색 영역이 유선(데스크탑), 파란색 영역이 무선(태블릿, 핸드폰)

- 태블릿으로도 할거고 데스크탑으로도 할거면 둘 다 사야되는건가?

- 바코드/QR, 애플페이 지원이 꼭 돼야한다 - 그러면 **NK-2500QN**
- 둘 다 필요없다 - 그러면 당연히 싼거 고르겠지 **NR-5500_QR**
- 서명 기능 내장 멀티패드가 꼭 필요하다 - 그러면 **NK-2500QN**
- 근데 태블릿으로 하면 **NM-400_BLE**도 꼭 필요하겠네.
- **이게 개념이 그러면 NM-400_BLE 기기랑 NVCAT 연동이 되는건가?**
	- 된다 - 무조건 사야지
	- 안된다 - 그럼 APPPOS 연동 방법으로 가야되는건데.. 이 자료도 필요한거네

- 그럼 지금 이게 만약에 PC랑 모바일 연동 방법이 다르고 기기도 다르면.. APPPOS 연동이랑 NVCAT 연동 방식을 같이 알아야 되는거네? 위에서 담당자에게 물어볼거 좀 물어보자..

- **안드로이드 POS 리더기 부착형 태블릿을 판매하고 있음. (검색 NTP-10 참고) 태블릿 본체, 카드리더기, 거치대로 구성돼있고 카드리더기와 거치대는 별도 구매. PC랑 모바일 둘 다 연동이 되면서 데몬 송수신을 이용하고 C타입으로 연결해서 사용할 수도 있음. 198,000 (부가세 별도)**

- 카드리더기를 헌터코리아에서 구매한 태블릿 본체에 연결해서 사용이 가능하다는 말인건지?
- 그냥 C타입에 연결해서 사용하면 되는건지? 보안 인증 같은건 거칠 필요가 없는건지?
