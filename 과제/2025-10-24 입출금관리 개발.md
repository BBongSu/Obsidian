## 기획

- 불필요한 화면 제거
	- 현금영수증 발행하기
	- 발행 선택

- 입금처리 한다.
	- 데이터 가라로 넣어서 입금처리

- 결제이력에 결제수단에 따른 증빙관리 버튼을 생성한다.
	- 카드결제로 했다면 카드명세서
	- 가상계좌로 했다면 세금계산서 또는 현금영수증
	- 현금결제로 했다면 현금영수증

- 증빙관리 버튼 누르고 세금계산서 내용을 조회할 수 있는 URL를 반환한다.

	- 바로빌 상세 정보 외부 연결 API(URL 기능 사용) - https://dev.barobill.co.kr/docs/references/%EC%84%B8%EA%B8%88%EA%B3%84%EC%82%B0%EC%84%9C-API
	
	- 세금계산서
		GetTaxInvoicePopUpURL - 내용보기 URL                                       
		GetTaxInvoicePopUpURLNK - 내용보기 URL (국세청 승인번호로 조회)          
		GetTaxInvoiceMailURL - 내용보기 URL (거래처 관점)                           
		GetTaxInvoiceMailURLNK - 내용보기 URL (거래처 관점) (국세청 승인번호로 조회)
		GetTaxInvoicePrintURL - 인쇄 URL                                           
		GetTaxInvoicePrintURLNK - 인쇄 URL (국세청 승인번호로 조회)              
		GetTaxInvoicesPrintURL - 인쇄 URL (여러건)                                
		GetTaxInvoicesPrintURLNK - 인쇄 URL (여러건) (국세청 승인번호로 조회)   
	
	- 현금영수증
		GetCashBillPopUpURL - 내용보기 URL
		GetCashBillPopUpURLNK - 내용보기 URL (국세청 승인번호로 조회)          
		GetCashBillMailURL - 내용보기 URL (수신자 관점)
		GetCashBillMailURLNK - 내용보기 URL (수신자 관점)
		GetCashBillPrintURL - 인쇄 URL
		GetCashBillPrintURLNK - 인쇄 URL
		GetCashBillsPrintURL - 인쇄 URL (여러건)

- 증빙관리 버튼을 클릭하면, 영수증을 발행하기 위한 모달창을 띄운다.
- 세금계산서 또는 현금영수증은 등록/상세페이지를 같이 사용한다. 
- 발행한 후에는 상세로 띄운다. 발행은 우선 1번만
