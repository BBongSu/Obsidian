실제로 실행되는 SQL

MyBatis가 #{}를 PreparedStatement의 ?로 바꿔요(확인). 실행 순서는 다음과 같아요.

-- 6. selectLotOne
SELECT *
  FROM stock_lot WITH (NOLOCK)
 WHERE lot_no = ?            -- lotNo

-- 10. updateLotQtyAndStatus
UPDATE stock_lot
   SET qty = ?, status = ?   -- remaining, 'AVAILABLE' | 'SOLD_OUT'
 WHERE lot_no = ?

- status는 enum 이름 문자열로 바인딩될 것으로 보여요. MyBatis 기본 EnumTypeHandler를 쓰기 때문이에요(추론).
- DB는 H2를 MODE=MSSQLServer로 돌려요(appliH2에서 실제로 잠금에 영향을 주는지는확인하지 않았어요. 운영 MSSQL에서는 READ UNCOMMITTED로 읽어요(추론).
