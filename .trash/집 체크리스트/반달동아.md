## 💰 **계약 관련 체크**

### 🔹 **1. 계약 기본 사항**

- [ ] **보증금 & 월세 금액** 확인 (변동 가능성 여부 포함)
- [ ] **계약 기간** (1년 or 2년, 단기 계약 가능 여부)
- [ ] **계약 갱신 시 월세 변동 여부** (임대인이 올릴 가능성 있는지)
- [ ] **이전 거주자 이사 이유** (집 상태에 문제 있는지 확인)
- [ ] **전세 / 월세 / 반전세 여부** (대출 가능 여부 포함)
- [ ] **중도 해지 시 위약금 여부** (조기 퇴실 시 조건 확인)
- [ ] **이사 가능 날짜** (언제부터 입주 가능한지)

### 🔹 **2. 관리비 및 추가 비용**

- [ ] **관리비 포함 항목** (수도, 인터넷, 청소비 포함 여부)
- [ ] **전기, 수도, 가스비 별도 여부** (개별 부과 or 포함)
- [ ] **인터넷 및 TV 요금 포함 여부**
- [ ] **주차비 추가 여부** (주차공간 유무 및 비용 확인)
- [ ] **엘리베이터 유지비** (별도 청구되는 경우 확인)
- [ ] **건물 공용 관리비** (경비, 청소비, 정화조 비용 등 포함 여부)
- [ ] **보일러 난방 방식** (개별 난방 or 중앙 난방, 난방비 평균 확인)

### 🔹 **3. 보증금 & 원상복구 조건**

- [ ] **보증금 반환 조건** (퇴실 시 돌려받는 방식)
- [ ] **벽지, 장판, 시설물 원상복구 여부**
- [ ] **보증금에서 수리비 차감 여부** (임대인 임의 차감 방지)
- [ ] **퇴거 전 청소 상태 요구 여부** (청소비 부과 여부)
- [ ] **고장 시 수리비 부담 주체** (임차인 vs 임대인)
- [ ] **에어컨, 보일러, 가전제품 유지 보수 책임자**

### 🔹 **4. 계약서 및 법적 사항**

- [ ] **임대차 계약서 작성 필수 여부**
- [ ] **확정일자 가능 여부** (보증금 보호 가능 여부)
- [ ] **등기부등본 확인** (집주인과 계약자가 동일한지 확인)
- [ ] **전입 신고 가능 여부** (주소 이전 문제 없는지)
- [ ] **체납 세금, 대출 여부 확인** (압류 위험 있는지)
- [ ] **계약 위반 시 페널티 조항 확인**
- [ ] **부동산 중개 수수료 확인** (계약 시 지불해야 하는 금액)
- [ ] **계약 종료 후 연장 가능 여부** (자동 갱신인지)

### 🔹 **5. 기타 사항**

- [ ] **반려동물 가능 여부**
- [ ] **흡연 가능 여부** (베란다, 실내)
- [ ] **배달음식, 택배 수령 공간 여부**
- [ ] **주방 및 공용시설 사용 제한 여부** (공용주택일 경우)
- [ ] **야간 소음 규칙 확인** (조용한 환경인지)
