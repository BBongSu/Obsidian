- 데이터 유효성 검사 - 데이터의 정확성과 일관성을 보장하기 위해 사용하는 검사
	- "반드시 이렇게 해야 한다"는 고정된 규칙이 정해져 있지 않음
	- 사용 목적, 업무 환경, 데이터의 종류에 따라 개발자나 사용자가 정의하는 규칙이 일반적
	
	- 규칙 유형 (보편적인 기준)
		- 필수 입력 - 필드가 비어 있으면 안되는 경우 (공백 방지)
		- 데이터 형식 - 이메일, 전화번호, 날짜
		- 범위 체크 - 수치 데이터가 특정 범위 안에 있는지 확인
		- 길이 체크 - 문자의 최소/최대 길이 제한 ex) 비밀번호 8자리 이상
		- 고유성 체크 - 아이디, 이메일 등 중복될 수 없는 데이터 검증
		- 일관성 체크 - 종료일이 시작일보다 앞설 수 없는 등 데이터 간의 논리적 순서
	
	- 적용 예시
		- 엑셀/스프레드시트
		- 웹 폼
		- 데이터베이스

- SOAP(Simple Object Access Protocol) - HTTP, HTTPS, SMTP 등을 통해 XML 기반의 메세지를 컴퓨터 네트워크 상에서 교환하는 프로토콜.

- RPA - 로보틱 프로세스 자동화. 데이터 입력 등의 단순한 반복 업무 프로세스의 자동화에 주로 적용할 수 있음. 예를 들어 사람이 하는 단순 반복적인 일을 대신하는 로봇

- 3rd party - 프로그래밍을 도와주는 plugin이나 library 등을 만드는 회사.

- RAG - AI의 주 문제점 중 하나인 잘못된 정보 "환각"을 줄여 실제 근거를 바탕으로 알려주는 기술. 내가 원하는 정보를 실시간으로 검색하면 그에 대한 정확도를 높여줌

- Optimistic UI
