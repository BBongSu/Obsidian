| **시대**    | **툴명**              | **주요 대응 언어**       | **핵심 특징 및 의의**                        |
| --------- | ------------------- | ------------------ | ------------------------------------- |
| **1950**  | **Punch Cards**     | Fortran,COBOL      | 물리적 종이 카드에 구멍을 뚫어 코딩하던 태동기 도구         |
| **1969**  | **ed**              | Assembly, C        | 유닉스(Unix)의 표준 라인 에디터, vi의 조상          |
| **1976**  | **vi**              | C, Shell Script    | 터미널 기반 스크린 에디터의 시초, 현재 **Vim**으로 계승   |
| **1976**  | **Emacs**           | Lisp, 다국어          | 극강의 확장성, 에디터 안에서 메일/게임까지 가능           |
| **1983**  | **Turbo Pascal**    | Pascal             | 컴파일러와 에디터를 합친 초기 IDE의 혁명              |
| **1991**  | **Visual Basic**    | Basic              | 드래그 앤 드롭 방식의 GUI(윈도우 앱) 개발 대중화        |
| **1991**  | **Vim**             | 다국어                | vi를 개선하여 플러그인과 모드 전환 기능을 극대화          |
| **1997**  | **Visual Studio**   | C++, VB, .NET      | Microsoft 생태계의 거대 통합 개발 환경(IDE)       |
| **2001**  | **Eclipse**         | Java (주로 사용)       | 오픈 소스 IDE의 대명사, 플러그인 생태계 구축           |
| **2001**  | **IntelliJ IDEA**   | Java, Kotlin       | '지능형' 코드 완성의 선구자, 현재 유료 IDE의 표준       |
| **2003**  | **Xcode**           | Objective-C, Swift | Apple(macOS, iOS) 생태계 전용 공식 개발 도구     |
| **2003**  | **Notepad++**       | 다국어                | 윈도우용 가볍고 빠른 오픈 소스 텍스트 에디터             |
| **2008**  | **Sublime Text**    | 다국어                | 미려한 UI와 빠른 속도로 '모던 에디터' 열풍을 주도        |
| **2013**  | **Android Studio**  | Java, Kotlin       | IntelliJ 기반의 구글 공식 안드로이드 개발 툴         |
| **2015**  | **VS Code**         | **거의 모든 언어**       | 전 세계 점유율 1위, 가벼운 에디터와 강력한 확장성         |
| **2021**  | **GitHub Copilot**  | 다국어                | AI가 코드를 제안하는 '페어 프로그래밍' 시대 개막         |
| **2023**  | **Cursor**          | 다국어                | VS Code 기반에 AI(LLM)를 완전히 내장한 차세대 에디터  |
| **2024~** | **Windsurf / Trae** | 다국어                | 단순 완성을 넘어 AI가 스스로 코드 맥락을 분석하는 에이전트형 툴 |
