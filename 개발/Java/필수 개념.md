## Map으로 Return할 때 JSTL에 되고 안되고의 케이스

- **Controller가 ModelAndView 또는 Model을 사용하는 경우**
	- 이 경우는 JSP로 forward(render) 되는 구조. 가능함
	- 예시)
``` java title="가능한 케이스"
@PostMapping("/test")
public String test(Model model) {
	ResponseEntity<String> response = rt.postForEntity(url, entity, String.class);
	
	Map<String, Object> rtnMap = new HashMap<>();
    rtnMap.put("response", response.getBody());

    model.addAttribute("rtnMap", rtnMap);

    return "/test.jsp";
}

... JSP (JSTL)

${rtnMap.response}
```

- **Controller가 @ResponseBody / @RestController인 경우**
	- 이 경우는 JSON 응답. JSP에서 JSTL로 받을 수 없음
	- 예시)
``` java title="불가능한 케이스"
@PostMapping("/test")
@ResponseBody
public Map<String, Object> test() {
    rtnMap.put("response", response.getBody());
    return rtnMap;
}
```

- 가능하게 하는 방법
	- 서버에서 Map으로 변환
	- 예시)
``` java title="가능한 방법"
ObjectMapper om = new ObjectMapper();
Map<String, Object> responseMap =
        om.readValue(response.getBody(), Map.class);

rtnMap.put("response", responseMap);
```
