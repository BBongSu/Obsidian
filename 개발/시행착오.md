- 상황
	- jsp javascript 소스 짤 때 백틱 내에 리터럴 문자열($)의 Number 함수 사용 (금액 입력 시 3자마다 , 찍어주기 위함)

- 이슈
	- 그 결과, jakarta.el.ELException: Function [:Number] not found 에러 발생

- 디버깅
	- 이 소스가 포함된 구간을 주석처리해도 해당 에러가 사라지지 않음. 백틱 내에 리터럴 문자열은 주석을 해도 오류 유지됨

- 해결
	- 백틱 내에 리터럴 문자열 선언이 아닌 function 만들어서 return 하는 방식으로 구현

``` javascript title="예제 코드"
function fmtN(v) { return Number(v || 0).toLocaleString(); }
function fmtS(v) { return v || ''; }
```
