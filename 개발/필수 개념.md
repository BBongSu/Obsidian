## 변수명을 잘 짓는 방법

- **명확하게 사용자의 행동을 나타내는 동사를 사용**
	- get - 값을 가져오다 ex) getUserName()
	- set - 값을 설정하다 ex) setUserName()
	- update - 값을 갱신하다 ex) updateProfile()
	- fetch - 데이터를 외부에서 가져오다 ex) fetchUserData()
	- calculate - 특정 값을 계산하다 ex) calculateUserPoint()
	- create - 새로운 것을 만들다 ex) createFile()
	- delete - 무언가를 삭제하다 ex) deleteFile()
	- add - 요소를 추가하다 ex) addItem()
	- remove - 요소를 제거하다 ex) removeItem()
	- validate - 유효성 검사를 하다 ex) validatePassword()
	- check - 확인하다 ex) checkPermission()
	- send - 데이터를 전송하다 ex) sendRequest()
	- load - 데이터를 로드하다 ex) loadPage()
	- save - 데이터를 저장하다 ex) saveProfile()
	- render - 화면에 표시하다 ex) renderData()
	- process - 처리하다 ex) processOrder()
	- initialize - 초기화하다 ex) initializeData()

- **상태나 특성을 나타내는 형용사 사용**
	- is - 주로 boolean 변수를 표현할 때 ex) isValid, isActive
	- has - 상태를 표현하는 변수일 때 ex) hasPermission, hasError
	- can - 가능한지 여부를 나타낼 때 ex) canSubmit, canEdit
	- should - 특정 조건을 만족해야 할 때 ex) shouldUpdate, shouldSave
	- current - 현재 상태를 나타낼 때 ex) currentPage, currentUser
	- previous - 이전 상태를 나타낼 때 ex) previousValue, previousPage
	- max - 최대값을 나타낼 때 ex) maxLength, maxValue
	- min - 최소값을 나타낼 때 ex) minAge, minValue

- **변수나 요소의 데이터 유형을 나타내는 명사 사용**
	- data - 데이터 ex) userData, productData
	- info - 정보 ex) contactInfo, profileInfo
	- list - 목록 ex) userList, taskList
	- item - 항목 ex) menuItem, cartItem
	- value - 값 ex) inputValue, currentValue
	- result - 결과 ex) queryResult, operationResult
	- error - 오류 ex) validationError, coneectionError
	- message - 메시지 ex) errorMessage, successMessage
	- count - 개수 ex) userCount, itemCount
	- index - 인덱스 ex) currentIndex, pageIndex
	- key - 키 값 ex) primaryKey, encryptionKey
	- type - 타입 ex) userType, responseType
	- status - 상태 ex) responseStatus, ordderStatus
	- config - 설정 ex) appConfig, serverConfig
	- token - 인증,토큰 ex) authToken, sessionToken

- **역할과 패턴을 명확히 하는 용어 사용**
	- callback - 콜백 함수 ex) fetchDataCallback()
	- handler - 이벤트 처리 함수 ex) clickHandler(), submitHandler()
	- service - 서비스 관련 함수나 객체 ex) emailService, paymentService
	- component - 컴포넌트 ex) HeaderComponent, FooterComponent
	- controller - MVC 패턴에서 컨트롤러 역할 ex) userController, orderController
	- model - 데이터 모델 ex) userModel, productModel
