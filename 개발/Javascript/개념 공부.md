- [ ] ## var / let / const 변수 차이점 5가지

### 1. 중복 선언 가능 여부

- var - 중복해서 선언 및 초기화가 가능
- let / const - 중복 선언 불가능

### 2. 재할당 가능 여부

- var / let - 값의 재할당이 가능한 변수
- const - 값의 재할당이 불가능한 상수

### 3. 변수 스코프 유효범위

- var - 함수 래벨 스코프. 함수 내부에 선언된 변수만 지역변수로 한정. 나머지는 모두 전역변수로 간주
- let / const - 블록 래벨 스코프. 함수 내부, if문이나 for문 등의 코드 블럭 { ... } 에서 선언된 변수도 지역변수로 취급

### 4. 변수 호이스팅 방식

``` javascript title="var - 변수 호이스팅 발생"
console.log(a);  // undefined
var a = 10;
console.log(a);  // 10

----------------------------------------------------------------------------

var a = undefined;
console.log(a);  // undefined
a = 10;
console.log(a);  // 10

```
``` javascript title="let / const - 변수 호이스팅 발생 (다른 방식으로 작동)"
console.log(a);  // ReferenceError: a is not defined
let a = 10;

----------------------------------------------------------------------------

let a; // 선언만 하고 정의는 하지 않음. var은 정의 하지않아도 undefined가 들어감.
console.log(a);  // ReferenceError: a is not defined
a = 10;
console.log(a); // 10
```
