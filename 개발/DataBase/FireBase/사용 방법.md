## 사용 방법 (정리중)

#### SDK 소스 적용

- 새 프로젝트 생성
- 프로젝트 다 만들었으면 "프로젝트 개요" 오른쪽 설정(톱니바퀴) 클릭 후 "SDK 설정 및 구성" 확인
- firebaseConfig 변수 확인 후 적용 (firebase.js 참고)
	- 파일만 만들어서 바로 적용하면 되는건지는 의문.. 확인 필요

#### Authentication

- 빌드 목록의 Authentication 메뉴 클릭
- 로그인 방법 클릭
- 목록에 이메일/비밀번호가 보이면 연필 아이콘(수정) 클릭
- 사용 설정 스위치를 키고 저장

#### 데이터베이스 만들기

- 빌드 목록의 Firestore Database 메뉴 클릭
- 화면 중앙에 있는 "데이터베이스 만들기" 클릭
	- 위치 - 기본값 그대로 두고 "다음" 클릭
	- 보안 규칙 - "테스트 모드에서 시작" 선택 후 만들기

#### 데이터베이스 규칙 수정하기

- 빌드 목록의 Firestore Database 메뉴 클릭
- 상단 탭 메뉴에서 "규칙" 탭 클릭
- 아래 소스 적용 후 "게시" 클릭

``` javascript title="규칙 적용"
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

#### 실시간 DB 데이터 확인

- 빌드 목록의 Firestore Database 메뉴 클릭
- "데이터" 탭 확인

#### 배포

- cmd에서 프로젝트 경로 진입 후 아래 명령어 입력

``` bash title="firebase 로그인"
npx firebase login
```

#### 코드 수정 후 재배포

``` bash title="코드 수정 후 재배포"
npm run build
npx firebase deploy
```
