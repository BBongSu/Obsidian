- **Ctrl + Shift + Z** - 앞으로 가기
- **Ctrl + G** - 줄번호로 바로 이동
- **Ctrl + Shift + F** - 파일 찾기
- **Ctrl + R** - 파일 내 코드 수정
- **Ctrl + Shift + R** - 프로젝트 내 코드 수정
- **Ctrl + Alt + L** - 코드 자동 정렬
- **Alt + 마우스 드래그** - 다중 커서 드래그
- **Alt + 1** - 좌측의 Project 창 열기, 닫기
- **Alt + 7** - 좌측의 Structure 창 열기, 닫기
- **Alt + F12** - Terminal 탭 열기
- **Ctrl + Shift + A** - 전체 찾기
- **Ctrl + F9** - 빌드
- **Shift + F10** - 빌드와 실행
- **Ctrl + F10** - 변경사항 적용 및 다시 시작
- **Shift + F9** - 디버그
- **F8** - Step Over
- **F7** - Step Into
- **Shift + F7** - Smart Step Into
- **Shift + F8** - Step Out
- **Control + F8** - breakpoint 전환
- **Control + Shift + F8** - breakpoint 보기
- **Shift + F6** - 이름 변경
- **Ctrl + F6** - 서명 변경
