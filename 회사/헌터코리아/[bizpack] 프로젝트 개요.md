## 1. 프로젝트 개요 (Project Summary)

- **프로젝트명**: 헌터코리아엔지니어링 차세대 사내 통합 관리 시스템 (BizPack)
- **대상 기업**: (주)헌터코리아엔지니어링 (Hunter Korea Engineering)
- **시스템 성격**: 영업, 엔지니어링/A/S, 재고/물류, 회계/정산, 자산관리 및 전자결재를 하나로 통합한 **B2B 엔지니어링·자재 맞춤형 통합 ERP / 사내 포털 시스템**
- **운영 도메인**: `bp.hunterkorea.com` (HTTPS / SSL Secure Communication)

---

## 2. 구축 목적 및 주요 배경 (Background & Objectives)

1. **부서 간 데이터 통합 및 일관성 확보**:
    - 영업(수주/견적), 현장 엔지니어링(A/S/설치), 재고(부품/제품), 회계(정산/지출결의) 부서 간 파편화된 데이터 단절 해소.
2. **정산 체계화 및 미수금/채권 추적 강화**:
    - 매출 확정 → 정산 검증 → 수금/입금 매칭 → 기간 마감의 5단계 정산 프로세스를 시스템화하여 거래처별 잔액 및 정산 이력을 실시간 파악.
3. **업무 이력 자산화 및 담당자 의존도 감소**:
    - 수기 문서나 개인 파일에 흩어져 있던 거래 이력, A/S 정비 이력, 차량 운행 일지, 결재 데이터를 DB화하여 업무 연속성 보장.
4. **외부 증빙 연동 자동화**:
    - 바로빌(Barobill) 연동을 통한 세금계산서·현금영수증·법인카드 매입 내역 자동 수집 및 결제 내역 자동 맵핑.

## 3. 핵심 모듈 및 기능 구성 (Core Modules)

| 모듈 코드             | 모듈명                 | 주요 기능 및 세부 내용                                                                                                                                                                         |
| ----------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`sal`**         | **영업 / 매출 관리**      | • 견적서 작성/관리 (`RcvEst`), 수주계약 등록/관리 (`RcvCntr`)  <br>• 거래처별 매출 현황 파악, 영업활동 일지 및 매출 목표 설정 (`SalGoal`, `SalAct`)                                                                         |
| **`pcm`**         | **구매 / 매입 관리**      | • 부품 및 제품 매입 등록 (`PrdBuy`), 일반비용/자산운영비용 등록  <br>• 구매 발주서 생성 및 관리 (`Cmp`), 자재/부품 수급 이력 관리                                                                                              |
| **`inv`**         | **재고 / 물류 관리**      | • 부품/제품 실시간 재고 현황 조회 (`Sto`), 입고/출고 처리 (`StkIn`, `StkOut`)  <br>• 재고 창고 이동 (`Mov`), 실사/바코드 관리 (`Pap`), 반품 및 회수 관리 (`Rcl`)                                                             |
| **`flp` & `wok`** | **현장지원 / A/S / 정비** | • A/S 접수·방문·수리 처리 (`Asr`), 장비 이전/인도/설치 관리 (`Inst`, `Dlvg`, `Pmv`)  <br>• 장애/사고 접수 (`Dis`), 전화/기술 상담 (`Tel`), 정기점검 및 교육 (`Edu`, `Prm`)  <br>• 작업지시서 발행 및 정비/엔지니어링 작업 관리 (`WokCon`)     |
| **`acc`**         | **회계 / 정산 / 급여**    | • **5대 지출결의서 작성/승인**: 제품·부품매입 / 일반비용 / 법인카드 / 자산운영비용 / 급여비용  <br>• **정산 및 미정산 잔액 자동 검증**: 정산 이력 자동 저장, 출금/입금 매칭  <br>• 법인카드 사용 내역 연동 (`Corpcard`), 급여/연차 승인 및 일정 관리 (`Sly`, `Annual`) |
| **`ast`**         | **자산 / 장비 관리**      | • 사내 고정자산 등록/이동/폐기 (`Fix`)  <br>• 업무용 차량 관리 (`Car`) : 차량 등록, 운행일지 작성, 정비 및 수리 이력 관리  <br>• 사내 창고 및 구역 관리 (`Wrh`)                                                                      |
| **`cus`**         | **거래처 / 고객 관리**     | • 거래처 기본정보 (`Info`), 사업자/계좌 정보 관리 (`Bsmn`)  <br>• 거래처별 정산 주기 및 여신 관리 (`Cycl`), 팩스/담당자 정보 관리 (`Fax`, `User`)                                                                           |
| **`doc` & `por`** | **전자결재 / 사내포털**     | • 전자결재 기안, 결재선 지정, 승인/반려 프로세스 (`San`)  <br>• 인트라넷 실시간 알림/쪽지 서비스 (Web Notification)  <br>• 사용자별 메뉴 권한 관리, 멀티 탭 UI (SPA 방식 화면 전환)                                                       |

## 4. 시스템 기술 아키텍처 (Technical Architecture)

![[Pasted image 20260807162535.png]]

- **Backend Framework**: Java 17, Spring Boot 3.2.6, MyBatis 3.0.3, Spring Session (JDBC)
- **Frontend Framework**: JSP (Spring MVC View), jQuery, Bootstrap Table, Feather Icons
- **Database**: MariaDB (P6Spy 기반 쿼리 파라미터 로깅 및 튜닝 모니터링)
- **외부 연동 패키지**:
    - `barobill-api-sdk-java17.jar`: 전자세금계산서 발행, 현금영수증, 법인카드 매입내역 수집
    - `NicePay`: 전자결제 연동
    - `Apache POI (5.2.5)`: 데이터 대량 엑셀 업로드/다운로드

## 5. 운용 및 배포 환경 (Operation Environment)

- **운영 서버 포트**: HTTPS 9443 (`bp_hunterkorea_com.p12` 인증서 적용)
- **파일 저장 경로**: `C:\uploads` (첨부파일 및 증빙 문서 저장)
