
### 참고

- 가비아 하이웍스 - https://biz-solution.hiworks.com/market/messenger
	- 반려 시, 일반 진행함에서 사라지고 별도의 반려 문서함으로 자동 이동

- 네이버 웍스 - https://help.worksmobile.com/ko/use-guides/approval/approve-document/
	- 반려 시, 문서의 진행을 멈추고 더 이상 진행하지 않음
	- 기안자가 "재기안" 버튼을 누르면 기존 내용을 복사해 새 창을 띄워줌

- 카카오 워크 - https://kakaowork.gitbook.io/kakao-work/hr/approval/user/get-started
	- 반려/전단계반려 - 문서에 문제가 있거나 결재가 불가능할 경우 기안자 혹은 전단계 결재자에게 문서를 반환
	- 기안자가 "회수" 또는 반려된 기안을 수정 후 "재상신"
	- 상신한 기안 중 반려된 문서는 "기안함"에 따로 보관

- 플랙스 - https://flex.team/
	- 반려 시, "히스토리" 탭을 따로 두어 본문과 이력을 분리

- 메일플러그 - https://groupware.mailplug.com/gw/trial
	- 반려 시, "기안 복사" 기능을 통해 새로운 문서로 파생시키는 구조

- 다우오피스 - https://demo4.daouoffice.com (user_demo1/daoudemo@2025)
	- 반려 처리 후, "재기안" 기능을 통해 문서 재작성

- 이카운트 - https://www.ecount.com/kr/ECK/ECK004M_CN.aspx
	- 반려 처리 후, "재기안" 기능을 통해 문서 재작성

- 제목 앞에 메타 데이터를 붙이는 방식
	- 반려 시 문서를 복제하되, 제목 앞에 hidden 값을 넣거라 [반려-260121] 같은 접두사를 붙여서 저장.
	- 목록 쿼리에서 최신 문서가 아니면서 제목에 특정 패턴이 있는 문서는 기본적으로 hidden 처리
	- "이력보기" 버튼 추가. 버튼 누르면 해당 문서의 이전 반려 건들만 팝업으로 뜸
